# Cram Cloud

A full-stack student notes sharing and discussion platform developed using React, Flask, and MySQL.

## Features

- User Authentication with JWT
- Role-Based Access Control
- Semester-wise PDF Notes Repository
- Community Discussion Forum
- PDF Comment System
- Admin Dashboard

## Tech Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Flask
- Python

### Database
- MySQL

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm start
```
